# Tend — tus hábitos y tu dinero

**Tend** es una aplicación de escritorio para llevar tus hábitos y tus finanzas personales en un mismo lugar.

Este repositorio solo contiene los instaladores. El código fuente vive en un repositorio privado.

## Descargar

**[Última versión](https://github.com/sebastian0912/tend-releases/releases/latest)** → descarga el archivo `.exe` y ábrelo.

Windows puede avisarte de que el editor es desconocido, porque el instalador todavía no está firmado. Pulsa «Más información» y después «Ejecutar de todas formas».

## Principios de diseño

- **Local-first.** Tus datos viven en tu equipo, no en un servidor ajeno. Desde Ajustes puedes guardar tu copia cuando quieras.
- **Se actualiza sola.** Al abrirse, la aplicación busca la versión nueva y la instala. No tienes que volver a descargar nada.
- **Un instalador, cero configuración.** Descargas, instalas y empiezas.

## Por qué los instaladores están en un repositorio público

La aplicación busca sus actualizaciones en las Releases de GitHub. Los archivos de una Release privada no se pueden descargar sin credenciales, así que una copia instalada recibiría un error 404 en cada comprobación. Por eso el código es privado y las descargas son públicas.
